Политика конфиденциальности

Настоящая Политика конфиденциальности распространяется на веб-версию проекта «Password Generator – Генератор паролей» , размещённую на сайте https://password-generator.dennymaverick.ru, и соответствующее мобильное приложение Android, распространяемое через RuStore.

1. Сбор и использование данных

Приложение «Password Generator – Генератор паролей» самостоятельно не запрашивает, не собирает, не хранит и не передаёт персональные данные пользователей.

Генерация паролей осуществляется непосредственно на устройстве пользователя. Созданные пароли не отправляются на внешние серверы и не передаются владельцу проекта. Приложение не требует подключения к интернету и не использует внешние сетевые сервисы для выполнения основных функций.

2. Генерация и хранение паролей

Все операции по созданию паролей выполняются локально на устройстве пользователя. Сгенерированные пароли предназначены для использования пользователем по собственному усмотрению. Приложение не сохраняет историю созданных паролей и не передаёт их третьим лицам. Владелец проекта не имеет доступа к сгенерированным паролям.

3. Локальное хранение настроек

Для обеспечения корректной работы и удобства использования веб-версии и мобильного приложения может использоваться механизм локального хранения данных (localStorage). В localStorage сохраняются исключительно пользовательские настройки интерфейса:

  • выбранный язык;
  • выбранная цветовая тема.

Указанные настройки хранятся локально на устройстве пользователя и используются исключительно для сохранения выбранных параметров интерфейса. Эти сведения не передаются владельцу проекта и не используются для идентификации пользователей.

4. Файлы cookie и сторонние сервисы

На момент публикации настоящей редакции Политики в проекте не используются сторонние сервисы веб-аналитики и рекламные сети.

В случае подключения таких сервисов, включая Яндекс.Метрику и Рекламную сеть Яндекса (РСЯ), настоящая Политика будет дополнена сведениями о целях использования соответствующих сервисов, категориях обрабатываемых данных и применяемых технологиях, включая файлы cookie.

5. Хостинг и техническая информация

Веб-версия проекта размещена на платформе GitHub Pages, предоставляемой компанией GitHub, Inc. При посещении веб-версии хостинг может автоматически обрабатывать техническую информацию, включая IP-адрес, дату и время обращения, запрашиваемую страницу, тип браузера и операционную систему пользователя. Такая обработка осуществляется инфраструктурой GitHub в целях обеспечения работоспособности, безопасности и защиты сервиса.

Владелец проекта не имеет прямого доступа к внутренним техническим журналам GitHub. Дополнительная информация об обработке данных доступна в Политике конфиденциальности GitHub .
